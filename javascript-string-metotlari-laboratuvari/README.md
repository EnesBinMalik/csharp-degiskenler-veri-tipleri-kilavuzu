# JavaScript String Metotları Laboratuvarı

Enes Öztürk tarafından hazırlanan, JavaScript metin metotlarını etkileşimli örneklerle ve alıştırmalarla inceleyen Türkçe eğitim uygulaması.

## İçerik

- Arama, ayıklama, dönüştürme ve biçimlendirme metotları kataloğu
- Metotları örnek girdilerle deneyebileceğiniz laboratuvar
- Karakter indeksleri ve UTF-16 kod birimleri için inceleyici
- Metot zinciri kurucu ve davranış karşılaştırmaları
- Otomatik testleri olan kod alıştırmaları ve yazdırılabilir kişisel ilerleme kartı

## Gereksinimler

- Node.js 20.19+ veya 22.12+
- npm

## Çalıştırma

Bu klasörde:

```bash
npm install
npm run dev
```

Vite geliştirme sunucusu `http://localhost:3000` adresinde açılır.

## Denetim ve derleme

```bash
npm run lint
npm run build
npm run preview
```

Laboratuvar örnekleri tarayıcıda JavaScript çalıştırır; ayrı bir sunucuya veya harici API anahtarına ihtiyaç duymaz. Yazdırılabilen ilerleme kartı uygulama içi kişisel özettir, akredite bir eğitim sertifikası veya resmi yetkinlik belgesi değildir.
