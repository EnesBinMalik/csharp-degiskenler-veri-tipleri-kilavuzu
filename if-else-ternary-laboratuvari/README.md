# C# If-Else ve Ternary Laboratuvarı

Enes Öztürk tarafından hazırlanan, C# koşullu dallanma ve ternary (`? :`) ifadesini örneklerle anlatan etkileşimli Türkçe eğitim uygulaması.

## İçerik

- `if-else` ve ternary ifadeyi adım adım karşılaştırma
- Akış şeması ve farklı koşul senaryoları
- Etkileşimli kod örnekleri ve bilgi testi
- Yazdırılabilir kişisel çalışma özeti

## Teknolojiler

- React 19 ve TypeScript
- Vite ve Tailwind CSS
- Lucide React

## Gereksinimler

- Node.js 20.19+ veya 22.12+
- npm

## Kurulum ve çalıştırma

Bu klasörde komutları çalıştırın:

```bash
npm install
npm run dev
```

Vite geliştirme sunucusu varsayılan olarak `http://localhost:3000` adresinde açılır.

## Denetim ve üretim derlemesi

```bash
npm run lint
npm run build
npm run preview
```

`npm run lint`, TypeScript denetimini; `npm run build`, üretim derlemesini çalıştırır. `npm run preview`, derleme çıktısını yerel olarak sunar.

## Kapsam ve doğruluk

Uygulama, örnek kodları ve çıktıları tarayıcıdaki önceden tanımlı simülasyonlarla gösterir; C# kodu derlemez veya CLR çalıştırmaz. Adım göstergesi gerçek hata ayıklayıcı değildir. Gösterilen dallanma, örnek C# kodunun kavramsal akışını açıklar.

Ternary (`? :`) bir değer üreten ifadedir; `if-else` ise deyim ve komut bloklarıyla dallanma sağlar. Hangi biçimin uygun olduğu okunabilirlik ve kullanım bağlamına bağlıdır; bu uygulama performans kıyaslaması yapmaz ve iki biçimin her zaman aynı IL ürettiğini iddia etmez.

Yazdırılabilir çıktı, uygulamanın oluşturduğu kişisel çalışma özetidir; resmi, kurumsal veya öğretmen onaylı bir teslim belgesi değildir.
