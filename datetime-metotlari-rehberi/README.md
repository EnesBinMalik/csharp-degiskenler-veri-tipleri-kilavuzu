# DateTime Metotları Rehberi

Enes Öztürk tarafından hazırlanan, JavaScript `Date`, `Intl` ve tarih/saat hesaplamalarını etkileşimli örneklerle inceleyen Türkçe eğitim uygulaması.

## İçerik

- `Date` oluşturma, okuma, değiştirme ve biçimlendirme metotları
- `Intl.DateTimeFormat` ve `Intl.RelativeTimeFormat` örnekleri
- Farklı IANA zaman dilimlerinde dünya saatleri
- Tarih farkı, süre ekleme ve biçim dönüştürme araçları
- JavaScript, C#, Python ve SQL için karşılaştırmalı kod örnekleri

## Gereksinimler

- Node.js 20.19+ veya 22.12+
- npm

## Çalıştırma

Bu klasörde:

```bash
npm install
npm run dev
```

Vite geliştirme sunucusu `http://localhost:3000` adresinde açılır.

## Denetim ve derleme

```bash
npm run lint
npm run build
npm run preview
```

Uygulama tarayıcıda JavaScript ile çalışır; C#, Python ve SQL bölümleri karşılaştırmalı örneklerdir, bu diller için çalışma zamanı içermez. Gösterilen tarih/saat sonuçları cihazın JavaScript çalışma zamanını ve saat dilimi verilerini kullanır.
